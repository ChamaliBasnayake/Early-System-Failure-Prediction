# Preprocessing record (every transformation that affects model input)

| Step | Script | Transformation | Parameters | Phase |
|---|---|---|---|---|
| Parse | `src/data/parse_bgl.py` | timestamps from the epoch field (UTC; the human-readable field is US/Pacific); each line split into 9 metadata fields + message (`split(maxsplit=9)`); lines with <9 fields dropped (0 in BGL); `is_alert = alert_tag != '-'`; rack / midplane / node-card derived from the node id; columns stored as plain strings (zstd Parquet) | — | 1 |
| Failure set | `src/data/failure_set.py` | target event = KERN* alert line excluding KERNMNTF/KERNMNT and excluding mass-synchronous incidents (>32 nodes within 60 s, same category); node episodes = target events within 300 s; incidents = episodes system-wide within 300 s; APP*/LINK*/MAS*/MON*/MMCS alerts kept as the non-target pool | `configs/failure_definition.yaml` | 1 |
| Masking | `src/data/templates.py` | node ids, I/O hosts, software version tags, 0x-hex, IPv4, paths, file names, hex words (≥6 chars with letters and digits) and plain numbers each replaced by the single wildcard `<*>`; whitespace normalised | `MASKS` list in the script (unit-tested) | 2 |
| Templates | `src/data/templates.py` | Drain3 fitted on the training period only; all lines matched in inference mode; unmatched → `UNK` (index 1); every distinct masked text also stored with a `masked_id` so an inductive pretrained text encoder can embed unseen messages; UNK rate and first-appearance split reported. A `--transductive-control` run (Drain on all data) exists as a labelled control only | `configs/drain3.ini` | 2 |
| Windows | `src/data/windows.py` | unit = midplane; two channels per window end t: LOCAL = the unit's events in [t−60 min, t], GLOBAL = all events in [t−60 min, t]; each channel = (template, masked text id, repeat-count, Δt) with consecutive repeats collapsed, last 256 items kept; summary counts (events, UNK, non-target alerts, other units' failure lines, active units); label per lead time N: a target unit-episode starts in [t+N, t+N+H); exclusions: failure visible in local window, 20 min post-episode, failure inside gap, mass-incident lines in window+horizon, span crossing a split cut | `configs/windows.yaml` | 2 |
| Negatives | `src/data/windows.py` | negatives drawn uniformly over (unit, minute) within each split period (the deployment process); hard negatives anchored 30 s after a non-target alert on the unit; positives at five offsets before the gap; exact-duplicate content removed within a split (same unit) and across splits (≥3 items) | `configs/windows.yaml` | 2 |

Personal data: none. BGL contains machine identifiers and system messages only; no anonymisation is required.
